# 账户密钥

账户密钥用于在脚本、自动化任务和第三方应用中调用 {{SITE_NAME}} 的账户接口，例如查询余额、订阅额度、令牌和使用日志。请求带上账户密钥即等同于已登录，无需处理密码、两步验证与登录状态续期

账户密钥与 API 令牌用途不同：API 令牌用于调用模型，账户密钥用于调用账户接口，两者不能互换

> **配置说明**
>
> 界面与接口可能随版本更新变化，以实际界面和返回内容为准。本页依据 2026 年 11 月 20 日核验的信息整理

## 生成账户密钥

每个账户只有一个账户密钥，在控制台和命令行工具中均可生成

在控制台中生成：

1. 在控制台打开 **个人主页**，切换到 **设置** 页签
2. 在 **账户密钥** 一栏点击 **生成**，确认提示后点击 **确定**
3. 在 **账户密钥已生成** 窗口中复制完整密钥并妥善保存，再点击 **我已保存**

在命令行工具中生成：打开 **个人主页**，在菜单的 **设置** 分组中选择 **生成账户密钥** 并确认，完整密钥显示在 **账户密钥已生成** 页面中，保存后选择 **我已保存**

> **注意**
>
> 完整密钥只在生成时显示一次，关闭后无法再次查看。遗失后重新生成即可，原密钥随之失效

## 重新生成与删除

生成账户密钥后，控制台中 **账户密钥** 一栏的按钮变为 **修改**，命令行工具中的菜单项变为 **修改账户密钥**。打开后可查看密钥的前后几位与生成时间，并进行以下操作：

- **重新生成**：生成新密钥并显示一次，原密钥立即失效
- **删除**：原密钥立即失效，之后可以重新生成

## 调用接口

账户接口的地址为 `{{SITE_URL}}/api` 加接口路径，请求头中带上账户密钥：

```text
Authorization: Bearer ak-您的账户密钥
```

例如查询账户余额与当日用量：

```sh
curl {{SITE_URL}}/api/dashboard/summary \
  -H "Authorization: Bearer ak-您的账户密钥"
```

返回类似下面的 JSON，即表示调用成功：

```json
{
  "balance": 10000000,
  "today": {
    "requests": 12,
    "tokens": 345678,
    "cost": 250000
  }
}
```

> **注意**
>
> 账户接口不支持跨域请求，其他网站的网页无法在浏览器中直接调用。在服务端、脚本等非浏览器环境中发起请求，也能避免账户密钥出现在网页代码中

### 常用接口

|接口|返回内容|
|---|---|
|`GET /api/dashboard/summary`|账户余额 `balance`，以及当日的请求数 `requests`、Token 用量 `tokens` 与费用 `cost`|
|`GET /api/subscriptions`|订阅列表，含套餐名称、生效时间 `startsAt`、到期时间 `expiresAt`，以及各额度窗口的总额度 `quota`、已用额度 `used` 与下次重置时间 `resetAt`|
|`GET /api/tokens`|令牌列表，含名称、分组、累计消费 `usedQuota` 与费用限制 `quotaLimit`，令牌只返回前后几位|
|`GET /api/logs?page=1`|使用日志，含模型、Token 用量、费用 `quotaCost` 与请求状态|
|`GET /api/quota-ledger?page=1`|额度流水，含变动类型、变动额度 `amount` 与变动后余额 `balanceAfter`|
|`GET /api/site-config`|站点公开配置，含额度换算比例 `quotaPerUsd`，无需账户密钥|

使用日志与额度流水分页返回：`page` 从 1 开始且必须填写，每页 100 条，从新到旧排列；`items` 为当前页内容，`total` 为总条数

订阅列表也包含已到期的订阅。`revokedAt` 为空、且当前时间处于 `startsAt` 与 `expiresAt` 之间的订阅正在生效；各额度窗口的剩余额度为 `quota` 减去 `used`

### 金额与时间

返回结果中的余额、费用与额度均为整数形式的额度单位，除以 `/api/site-config` 返回的 `quotaPerUsd` 即为美元金额。例如 `quotaPerUsd` 为 `500000` 时，`balance` 为 `10000000` 表示余额 $20.00

时间均为 UTC 时间的 ISO 8601 字符串，例如 `2026-11-20T06:30:00.000Z`；控制台按北京时间显示，换算时加 8 小时

### 其他接口

控制台网页的全部功能都通过 `/api` 下的接口实现，账户密钥都可以调用，包括创建与修改令牌、提交工单等写操作。需要其他接口时，在浏览器开发者工具的 **网络** 面板中查看控制台发出的请求地址、参数与返回内容，再用账户密钥发起相同的请求

### 错误响应

请求失败时返回对应的 HTTP 状态码，响应体格式如下：

```json
{
  "error": {
    "code": "unauthorized",
    "message": "unauthorized",
    "requestId": "3f2b8c1e-7d4a-4e9b-a6c5-1b2d3e4f5a6b"
  }
}
```

`code` 为错误标识，程序应据此判断失败原因，不要依赖 `message` 的内容；通过 **工单支持** 反馈问题时附上 `requestId`

## 安全须知

账户密钥的权限与登录后相同：持有密钥即可调用全部账户接口，可以创建令牌、添加 Passkey、启用两步验证，也可以重新生成或删除账户密钥本身。保管要求高于 API 令牌

- 只在自己信任的环境中使用，不要写入网页前端代码、公开仓库、截图或日志；提交日志或截图前先脱敏
- 只需要调用模型的场景使用 [API 令牌](/guides/access.md#api-令牌)，不要提供账户密钥
- 修改密码、重置密码和 **退出所有设备** 都不会让账户密钥失效。疑似泄露时，先重新生成或删除账户密钥，再检查密码、登录设备、两步验证与 Passkey
- 使用账户密钥修改密码或邮箱后，所有已登录的设备都会退出登录
- 不再使用时删除账户密钥

## 常见问题

|现象|处理方式|
|---|---|
|返回 401 `unauthorized`|核对请求头与密钥；重新生成或删除后原密钥失效|
|返回 403 `account_disabled`|账户已被禁用，联系管理员处理|
|返回 400 `validation_error`|核对参数，例如分页接口必须带 `page`|
|返回 429 `rate_limited`|操作过于频繁，稍后重试|
|用账户密钥调用模型返回 401|调用模型使用 API 令牌，账户密钥只用于账户接口|
|浏览器中跨域请求失败|改在服务端或脚本中调用|
|金额数值与控制台不一致|接口返回额度单位，除以 `quotaPerUsd` 换算为美元|
